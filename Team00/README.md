## 📌 О проекте

Этот проект предназначен для анализа данных из базы MovieLens. В рамках работы были сделаны:
- Python-модуль для обработки данных
- Тестирование с помощью PyTest
- Аналитический отчет в Jupyter Notebook

## 📂 Структура проекта

- data-folder - исходные данные
- movielens_analysis.py - основной модуль для работы с данными
- movielens_analysis.ipynb - аналитический отчет в Jupyter Notebook
- requirements.txt - используемые библиотеки

## 📋 Реализованные классы

В проекте реализованы 4 основных класса для анализа данных MovieLens:

1. Links - работает с внешними ссылками на фильмы. Основные методы:

- Получение данных с IMDB (режиссеры, бюджет, сборы, хронометраж)

- Топ режиссеров по количеству фильмов

- Самые дорогие и прибыльные фильмы

- Фильмы с наибольшей длительностью

- Фильмы с максимальным бюджетом в минуту экранного времени

2. Movies - анализирует данные о фильмах. Ключевые функции:

- Распределение фильмов по годам выпуска

- Статистика по жанрам

- Фильмы с наибольшим количеством жанров

3. Ratings - обрабатывает оценки пользователей, содержит два подкласса:

- Movies - анализ оценок по годам, рейтингам, топ фильмов по количеству оценок и их противоречивости

- Users - статистика по пользователям: активность, средние оценки, вариативность оценок

4. Tags - работает с пользовательскими тегами:

- Теги с наибольшим количеством слов и символов

- Популярные теги и теги, содержащие указанное слово

- Пересечение самых длинных и многословных тегов
